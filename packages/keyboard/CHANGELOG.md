- Render display-only SVG piano keyboards in either orientation, with inclusive MIDI ranges, container or fixed sizing, and programmatic pressed state.
- Choose from Minimal, Classic, Realistic, Modern, Neon, Dark, and High Contrast, or register a custom appearance for a mounted instance. Realistic adds acoustic-piano keytop shading, bevels, edge reflections, and contact shadows.
- Configure motion, pressed markers, labels, highlights, overlays, and accessible names and descriptions. Mark redundant diagrams decorative.
- Use visualization events, geometry-backed hit testing, and visual extensions through the public API.
- Render self-contained static SVG in Node. Mount in browsers and embedded hosts using ESM or the offline classic scripts.
- Explore the API in the development playground and export the current diagram as static SVG.
